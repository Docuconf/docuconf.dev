# Example apps

Every SDK repository has a runnable example: the same small HTTP service, **orders**, built with that language's usual tools. Comparing them shows how each SDK fits its host library while producing the same kind of contract.

Each example:

- declares its configuration with the SDK, in the host library's own style;
- serves `GET /healthz` and `GET /config`, which shows the typed values with the secret redacted;
- commits the `contract.cue` it exports, and CI checks that it is up to date and passes `cue vet`;
- fails at startup with every problem listed, each with an error code, when the configuration is wrong. Each README shows the real output.
